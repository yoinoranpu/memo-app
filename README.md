# メモアプリ

画面の一番上に常駐する、クリックするだけで書ける・チェックできるメモアプリ（Electron + React + Vite + Zustand）。

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev
```

トレイアイコンから「設定」でショートカット変更・自動起動のON/OFFができる。

## 型チェック・テスト

```bash
npm run typecheck
npm run test
```

## パッケージング (Windows exe)

```bash
npm run dist
```

`dist/` にNSISインストーラーが生成される。

## 補足：`npm install`後にElectronが起動しない場合

環境によっては(このプロジェクトのNode.js v24環境で確認済み)、Electron本体のインストール処理(zip展開)がライブラリ側の非互換性で途中で止まってしまい、`npm run dev`が`Error: Electron uninstall`で失敗することがある。`npm install`のたびに自動で`scripts/fix-electron-install.cjs`が実行され、この状態を検出して修復するようにしてあるので、通常は意識しなくてよい。もし発生した場合は、もう一度`npm install`を実行すれば直る。

## 配布前にやっておくこと（他人に渡す/公開する場合）

- **初回起動時の同意ページ**：`hasAcceptedDisclosure`がfalseの間、通信を行わない旨・データはローカル保存のみである旨・免責事項を表示する同意ページ(`src/renderer/src/app/ConsentApp.tsx`)が最初に表示され、同意するまでメモの復元やショートカット登録が行われない。設定画面の「このアプリについて」からいつでも同じ内容を見返せる。文面を変える場合は`ConsentApp.tsx`内の`POINTS`配列を編集する。
- **LICENSE**：MITライセンスを同梱済み（[LICENSE](LICENSE)）。著作権者名はGitHubのハンドルネーム（yoinoranpu）にしてある。本名を晒さずに「誰の作品か」を示せる、就活ポートフォリオ用途とネットリテラシーのバランスを取った選び方。
- 上記2つは「個人情報を一切収集しない・通信しない」という前提の上での最低限の対策。

## 既知の制限事項

- **排他フルスクリーンのゲームなどの上には表示できない場合がある**：`setAlwaysOnTop(true, 'screen-saver')` で最高レベルの最前面表示を行っているが、DirectX/OpenGLの排他フルスクリーンモードはOS/ドライバー側でデスクトップコンポジタをバイパスするため、Electron側から確実に上に表示する方法がない。ウィンドウモード/ボーダレスウィンドウのゲームであれば問題なく表示される。
- **「背面に送る」は簡易実装**：Electronには複数の常時最前面ウィンドウ間の厳密なz-order APIが無いため、対象メモのalways-on-topレベルを一時的に下げることで近似している。他の通常ウィンドウの後ろにも回り込む場合がある。
- **未署名exeの警告**：コード署名をしていないため、配布・インストール時にWindows SmartScreenの警告が表示される。自分のPCで使う分には「詳細情報」→「実行」で問題ない。配布する相手には事前に一言伝えておくと親切。
- **タッチパネル非対応**：ドラッグ・リサイズ・右クリックメニューはすべてマウス専用の実装（マウスイベントベース）。タッチ操作（特に右クリックに相当する操作）には対応していない。対応するにはPointer Events APIへの作り替えと、右クリックメニューを長押し操作に置き換える設計変更が必要（長押しは現在ドラッグに使っているため、操作の衝突を避ける設計も必要）。実装しない方針で確定済み。
