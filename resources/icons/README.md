## 反映済みのもの（すぐ使える）

上表で✅のものは `resources/icons/<ファイル名>.png` として保存すれば、アプリを再起動するだけで反映される。まだファイルが無い項目は自動的にアイコン無し（テキストのみ）で表示されるので、一部だけ先に置いても問題ない。

## 未配線のもの（イラスト到着後にコード側の追加対応が必要）

`icon_undo` / `checkbox_unchecked` / `checkbox_checked` / `corner_fold` / `onboarding_illustration` はメモのウィンドウ内（React側の画面）に表示する部品のため、現在のnative側の仕組み（`loadIcon`）とは別の組み込み方が必要。ファイルができたらこのフォルダに置いた上で一声かけてもらえれば、表示側のコードを追加する。それまでの間、チェックリストは標準のチェックボックス表示のまま動作する（機能的には問題ない）。
